这份 **AIPanel.jsx** 是你整个阅读器里**AI 能力的核心面板**，功能非常完整、成熟，我给你用最清晰的结构讲透：

# 整体定位
右侧 AI 侧边栏，实现：
- 文本解释 / 翻译 / 总结 / 提问
- **图片 OCR、识图、多模态对话**
- 每本书独立保存聊天历史
- 拖图 / 粘贴图片 / 上传图片
- 不支持图片的模型自动降级兼容
- 对接豆包 / DeepSeek 等 OpenAI 格式接口

---

# 1. 内置 AI 快捷模式（非常实用）
```js
const AI_MODES = [
  { id: 'explain',    label: '解释',   prompt: ... },
  { id: 'translate-zh', label: '译中', ... },
  { id: 'translate-en', label: '译英', ... },
  { id: 'summarize',  label: '总结',   ... },
  { id: 'knowledge',  label: '提炼',   ... },
  { id: 'ask',        label: '提问',   ... },
];
```
用户在阅读区**选中文本**，点一下就能：
解释、中译、英译、总结、提炼知识点、自动问答。

---

# 2. 核心状态管理
- `messages`：对话历史
- `inputText`：用户输入
- `contextText`：阅读区选中的文字（上下文）
- `images`：上传/粘贴的图片
- `loading / error`：请求状态

---

# 3. 按书籍独立保存聊天历史（很强）
```js
const key = `chat-history-${sanitizeKey(book.filePath)}.json`
```
- 每本书的 AI 对话**单独保存**
- 关闭再打开依然存在
- 用文件名哈希做 key，不会冲突

---

# 4. 超强图片能力
支持三种方式输入图片：
1. **粘贴图片**（Ctrl+V）
2. **拖入图片**到输入框
3. **点击上传**

内部逻辑：
- 转 dataURL
- 预览图 + 可删除
- 发送时组 **multimodal 格式**
- 模型不支持图片时**自动降级提示**

---

# 5. 两种 AI 触发方式
## ① 阅读区选中文本 → 快捷按钮
触发：解释 / 翻译 / 总结等
自动把选中文字作为上下文发给 AI。

## ② 自由提问
可搭配上下文，也可纯聊天、图片问答。

---

# 6. 自动处理 OCR
当阅读区触发 `mode === 'ocr'` 时：
```js
handleSend('请提取这张图片中的所有文字...', ...)
```
直接对图片执行 OCR，并自动返回文本，
适合**扫描版 PDF**。

---

# 7. 兼容不支持图片的模型
如果接口报错不支持 `image_url`，会自动重试：
```js
const textOnly = prompt + '\n\n[用户上传了图片...]'
```
保证不会直接崩溃，体验很稳。
